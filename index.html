🧠 Digital devices as ICT systems

A digital device is not just a screen or keyboard. It is a system that accepts data, processes data, stores data and outputs information. In iGCSE ICT, students need to explain the purpose of common hardware and justify which device is most suitable for a real scenario.

⌨️ Input, output and storage

Input devices include keyboards, mice, scanners, microphones, sensors and cameras. Output devices include monitors, speakers, printers and projectors. Storage includes HDDs, SSDs, optical media and cloud storage. A high-quality answer compares suitability, speed, capacity, cost, portability and durability.

🎯 Activity 1: Recommend the right device

A school wants to set up a digital art classroom. Recommend suitable input, output and storage devices. Explain why each one is appropriate and what limitation it might have.

🧩 Exam practice

A business is replacing desktop computers with tablets. Explain two advantages and two disadvantages of this decision. Include device suitability and user needs in your answer.

Write a structured response using accurate ICT vocabulary. Explain the concept, give an example from a school or business context, and evaluate one advantage and one limitation.

🔌 What is a network?

A network is a group of connected devices that can communicate and share resources. Schools use networks for logins, file storage, printers, internet access, email and learning platforms. Students should explain both the benefits and the risks of networked systems.

🏫 LANs and WANs

A LAN usually covers one home, school or office building. A WAN covers a much larger area and may connect many LANs together. A strong iGCSE explanation uses scale, ownership, cost, security and speed to compare the two.

🎯 Activity 1: Design a school network

Design a basic network for a new ICT room. Include users, devices, servers, Wi-Fi, printers and internet access. Explain how the network supports learning and how it should be protected.

🧩 Exam practice

Explain why a school might use a LAN rather than standalone computers. Include file sharing, resource sharing and network security in your answer.

🛡️ Why security matters

ICT systems store sensitive personal, financial and organisational data. Network security is about preventing unauthorised access, accidental loss, malware, phishing and insider misuse. Students need to match threats to suitable protection methods.

🔑 Protection methods

Common methods include strong passwords, user access levels, firewalls, anti-virus software, encryption, backups and staff training. Strong answers explain the purpose of each method and why no single method is enough.

🎯 Activity 1: Security audit

A small business has weak passwords, shared logins and no backups. Write a short security report explaining the risks and recommending improvements.

🧩 Exam practice

🧮 Spreadsheet modelling

A spreadsheet can model business, scientific or school data. Students need to understand cells, rows, columns, formulae, functions, formatting, validation, sorting, filtering and charts. The most powerful answers explain why a spreadsheet method is efficient.

📈 Formulae, functions and charts

Formulae begin with = and can use operators such as +, -, * and /. Functions such as SUM, AVERAGE, MIN, MAX and IF make common calculations quicker. Charts should be selected based on the data: bar charts for comparisons, line charts for trends and pie charts for proportions.

🎯 Activity 1: Build a school trip cost model

Design a spreadsheet model for a school trip. Include ticket cost, transport cost, number of students, total cost, average cost per student and a chart showing cost categories.

🧩 Exam practice

Explain why a spreadsheet is useful for modelling costs. Include formulae, automatic recalculation and charts in your answer.

📝 Document design

🎨 Professional formatting

🧩 File types and images

Digital media depends on choosing appropriate file formats. Students need to compare JPEG, PNG, GIF, SVG, PDF and document formats in terms of quality, compatibility, file size and purpose.

🖼️ Bitmap and vector graphics

Bitmap images are made of pixels and can lose quality when enlarged. Vector images are made from shapes and can scale without losing clarity. Strong answers link image type to purpose: photos often use bitmap formats; logos often use vector formats.

🎯 Activity 1: Choose the right file format

A company needs a logo, a product photo and a printable poster. Recommend suitable file formats and explain why each format is appropriate.

🧩 Exam practice

Explain how compression can reduce file size and why this might affect image quality.

📚 What is a database?

A database stores structured data so it can be searched, sorted and reported efficiently. A school database might store student names, classes, attendance, assessment marks and contact information.

🔎 Tables, queries and reports

A table stores records in rows and fields in columns. A query extracts data based on criteria. A report presents the results clearly for a particular audience. Students should explain how databases reduce duplication and improve retrieval.

🎯 Activity 1: Design a library database

Design a database for a school library. Include suitable fields, data types, validation rules and two useful queries.

🧱 HTML structure

HTML is used to structure web pages. Tags such as headings, paragraphs, images, links, lists and tables describe the content. Students need to be able to read, edit and create simple web pages.

🎨 CSS presentation

CSS controls how the page looks: colours, fonts, spacing, borders, layout and responsiveness. In iGCSE ICT, students should understand the difference between structure and presentation, and explain why separating content and style is useful.

🎯 Activity 1: Build a revision page

Create a simple HTML revision page for one ICT topic. Include a heading, paragraph, image, link, list, table and CSS styling.

🧩 Exam practice
