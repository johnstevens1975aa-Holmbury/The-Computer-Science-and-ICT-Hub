💻 TOPIC 1

Digital Devices, Input, Output and Storage

How ICT systems receive data, process information, store files and present results.

✕ Close
📅⭐🌍🤖
📘 🔎 Inquiry 📘 📝 Written Analysis 📘 🧠 Metacognitive Thinking 🔬 Analysis 💡 Intellectual Curiosity 🔗 Making Connections 🎯 Self-awareness SDG 4: Quality Education SDG 9: Industry, Innovation & Infrastructure 🔍 AI Critical Thinking ⚖️ AI Ethics
📚 Knowledge Organiser
  • Hardware is the physical equipment in an ICT system.
  • Input devices enter data, output devices present information, and storage devices save data.
  • Primary storage works directly with the processor; secondary storage keeps files long term.
  • Suitability depends on user needs, cost, speed, capacity, portability, durability and accessibility.

💻 Digital devices as systems

A digital device is a system that accepts data, processes it, stores it and produces information. In Edexcel iGCSE ICT, students need to describe the purpose of common devices and explain why one device is more suitable than another for a specific user or organisation.

⌨️ Input, output and storage

Input devices include keyboards, scanners, microphones, barcode readers, cameras and sensors. Output devices include monitors, speakers, printers and projectors. Storage devices include SSDs, HDDs, memory cards, optical media and cloud storage. Strong answers compare features rather than simply naming devices.

📌 Worked example

A school setting up a digital art classroom would need graphics tablets or touchscreens for input, high-resolution monitors for output and cloud storage or SSDs for saving large image files. A clear answer would also explain limitations such as cost, training and file size.

🎯 Activity 1: ICT application task

A new ICT room is being designed for creative media students. Recommend suitable input, output and storage devices. Explain why each choice is appropriate and identify one limitation.

🌐 TOPIC 2

Connectivity, Networks and Communication

How devices connect, communicate and share resources across local and wide area networks.

✕ Close
📅⭐🌍🤖
📘 🔎 Inquiry 📘 📝 Written Analysis 📘 🧠 Metacognitive Thinking 🔬 Analysis 💡 Intellectual Curiosity 🔗 Making Connections 🎯 Self-awareness SDG 4: Quality Education SDG 9: Industry, Innovation & Infrastructure 🔍 AI Critical Thinking ⚖️ AI Ethics
📚 Knowledge Organiser
  • A network connects devices so they can share data and resources.
  • A LAN covers a small area; a WAN covers a wider geographical area.
  • Bandwidth, latency, reliability and security affect network performance.
  • The internet is a global network of connected networks.

🔌 What a network does

Networks allow users to share files, printers, internet connections and services. A school network supports logins, learning platforms, email, printing and secure file storage.

🏫 LANs and WANs

A LAN usually covers one site, such as a school building. A WAN connects larger areas and may link different sites or organisations. Comparing the two requires more than size: ownership, cost, reliability, speed and security all matter.

📌 Worked example

A school may use a LAN for classroom computers and a WAN or internet connection to access cloud services. Students should be able to explain both the benefits and the risks of increased connectivity.

🎯 Activity 1: ICT application task

A new school wants a reliable network for classrooms, offices and student devices. Design a basic network and explain how it supports learning and security.

🔐 TOPIC 3

Network Security, Data Protection and Safe Use

How organisations protect accounts, devices, networks and sensitive data.

✕ Close
📅⭐🌍🤖
📘 🔎 Inquiry 📘 📝 Written Analysis 📘 🧠 Metacognitive Thinking 🔬 Analysis 💡 Intellectual Curiosity 🔗 Making Connections 🎯 Self-awareness SDG 4: Quality Education SDG 9: Industry, Innovation & Infrastructure 🔍 AI Critical Thinking ⚖️ AI Ethics
📚 Knowledge Organiser
  • Cybersecurity protects systems and data from unauthorised access.
  • Passwords, permissions, firewalls, backups and anti-malware reduce risk.
  • Encryption makes data unreadable without the correct key.
  • Users are often a major security risk if training and procedures are weak.

🛡️ Why security matters

ICT systems store personal, financial and organisational data. Security protects confidentiality, integrity and availability. Students need to match realistic threats to suitable protection methods.

🔑 Protection methods

Firewalls monitor traffic, anti-malware detects threats, permissions limit access, encryption protects data and backups support recovery. A strong exam response explains why several layers are needed together.

📌 Worked example

A business with shared passwords, no backups and no staff training is vulnerable. A good security report would recommend unique logins, stronger passwords, role-based access, firewall settings, anti-malware, backups and staff awareness training.

🎯 Activity 1: ICT application task

Write a short security audit for a small business. Identify three risks and recommend a suitable protection method for each risk.

Spreadsheets, Formulae, Functions and Charts

Using spreadsheet models to calculate, analyse and communicate data.

✕ Close
📅⭐🌍🤖
📘 🔎 Inquiry 📘 📝 Written Analysis 📘 🧠 Metacognitive Thinking 🔬 Analysis 💡 Intellectual Curiosity 🔗 Making Connections 🎯 Self-awareness SDG 4: Quality Education SDG 9: Industry, Innovation & Infrastructure 🔍 AI Critical Thinking ⚖️ AI Ethics
📚 Knowledge Organiser
  • Spreadsheets store data in cells arranged by rows and columns.
  • Formulae perform calculations; functions are built-in formulae.
  • Relative and absolute references control how formulae copy.
  • Charts communicate trends, comparisons and proportions.

🧮 Spreadsheet modelling

A spreadsheet model can represent costs, marks, stock, surveys or scientific data. It allows automatic recalculation when values change and can make decisions through functions such as IF.

📈 Formulae, functions and charts

Formulae begin with = and can use operators such as +, -, * and /. Functions such as SUM, AVERAGE, MIN, MAX, COUNTIF and IF make common tasks faster. Charts should be selected to suit the data.

📌 Worked example

A school trip spreadsheet could calculate total cost, average cost per student and profit or loss. A chart could compare transport, ticket and food costs.

🎯 Activity 1: ICT application task

Design a spreadsheet model for a school trip. Include total cost, average cost per student and a chart showing cost categories. Explain why a spreadsheet is suitable.

  • Document production communicates information through structure and layout.

📝 Professional document design

Document production is about using structure, formatting and layout to communicate clearly. Students should explain how choices such as headings, spacing, alignment, images and captions support audience and purpose.

🎨 Accuracy and consistency

In iGCSE ICT practical tasks, following the brief is essential. Consistent styles, correct page setup, good image placement and accurate proofreading can separate a strong response from a weak one.

📌 Worked example

A school newsletter should use a clear title, consistent headings, suitable images, captions, tables, white space and a footer. The design should not distract from the message.

Files, Images, Layout and Digital Media

Choosing suitable file types, image formats and layouts for different purposes.

✕ Close
📅⭐🌍🤖
📘 🔎 Inquiry 📘 📝 Written Analysis 📘 🧠 Metacognitive Thinking 🔬 Analysis 💡 Intellectual Curiosity 🔗 Making Connections 🎯 Self-awareness SDG 4: Quality Education SDG 9: Industry, Innovation & Infrastructure 🔍 AI Critical Thinking ⚖️ AI Ethics
📚 Knowledge Organiser
  • File type affects quality, compression and compatibility.
  • Bitmap images store pixels; vector images store shapes and paths.
  • Resolution, colour depth and compression affect size and quality.
  • Good layout uses proximity, contrast, alignment and repetition.

🧩 File types

Different file types are suitable for different jobs. JPEG is common for photographs, PNG supports transparency, SVG is useful for scalable logos and PDF preserves layout for sharing.

🖼️ Bitmap and vector images

Bitmap images can lose quality when enlarged because they are made of pixels. Vector graphics are made from shapes and can be resized without losing sharpness. Students should link image type to purpose.

📌 Worked example

A business might use SVG for a logo, JPEG for a website photo and PDF for a printable brochure. A strong answer explains why each choice fits the task.

🎯 Activity 1: ICT application task

Recommend file formats for a company logo, product photo and printable poster. Explain quality, file size and compatibility for each choice.

Databases, Tables, Queries and Reports

Organising data so it can be searched, filtered, sorted and reported.

✕ Close
📅⭐🌍🤖
📘 🔎 Inquiry 📘 📝 Written Analysis 📘 🧠 Metacognitive Thinking 🔬 Analysis 💡 Intellectual Curiosity 🔗 Making Connections 🎯 Self-awareness SDG 4: Quality Education SDG 9: Industry, Innovation & Infrastructure 🔍 AI Critical Thinking ⚖️ AI Ethics
📚 Knowledge Organiser
  • A database stores organised data in tables.
  • Records are rows; fields are columns.
  • Queries search or filter data using criteria.
  • Reports present selected database information clearly.

📚 What databases do

Databases are used when data needs to be stored, searched, sorted and reported efficiently. A school might use a database for students, classes, attendance, assessment data and contact details.

🔎 Tables, queries and reports

Tables store data, queries extract data and reports present data for an audience. Students should explain the benefit of validation, data types, primary keys and reduced duplication.

📌 Worked example

A library database might include fields for book ID, title, author, genre, borrower and due date. A useful query could show overdue books or all books by one author.

🎯 Activity 1: ICT application task

Design a library database. Include suitable fields, data types, validation rules and two queries that would help library staff.

📚 Knowledge Organiser
  • HTML structures web content.
  • CSS controls presentation, layout and style.
  • Links, images, headings, lists and tables are common web elements.
  • Good web design considers usability, accessibility and audience.

🧱 HTML structure

HTML is used to structure web page content through tags such as headings, paragraphs, links, lists, images and tables. Students need to read, edit and create simple page structures.

🎨 CSS presentation

CSS controls presentation: colours, fonts, spacing, borders, layout and responsiveness. Separating structure and style makes pages easier to maintain and update.

📌 Worked example

A revision web page might include a main heading, summary paragraph, image with alt text, resource links, a vocabulary list and a table of key terms.
